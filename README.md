## ✨ Features

- 📁 **Organize** - Section → Subsection → Title hierarchy
- 🔍 **Search** - Find playgrounds by title, section, or subsection
- ✏️ **Edit** - Add, update, or delete playgrounds
- 👁️ **Preview** - View HTML in embedded iframe
- 💾 **Persist** - All data stored in browser localStorage
- 🎨 **Beautiful UI** - Modern, responsive design

---

## 💡 Example

**Section**: Deep Learning  
**Subsection**: Neural Networks  
**Title**: CNN Visualization  
**Content**: Your HTML code

---

## 🚀 Quick Start

1. Click **"Add New Playground"**
2. Fill in Section, Subsection, Title, and HTML code
3. Click **"Save"**
4. Search and view your playgrounds!

---

## 🧰 Technical

- Pure HTML/CSS/JavaScript (no frameworks)
- Data stored in browser localStorage
- Works offline
- No server required

---

## 🚀 Deploy

- **Hugging Face**: Upload `index.html` and `README.md`
- **GitHub Pages**: Upload as `index.html`
- **Local**: Open `index.html` in browser
