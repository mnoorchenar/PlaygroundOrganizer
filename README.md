# PlaygroundOrganizer

**True 3-way sync** between:
- **Local**: E:\HuggingFace\PlaygroundOrganizer
- **GitHub**: https://github.com/mnoorchenar/PlaygroundOrganizer
- **Hugging Face**: https://huggingface.co/spaces/mnoorchenar/PlaygroundOrganizer

## Usage

**Push changes:**
`powershell
.\sync.ps1 "Your commit message"
`

**Pull without pushing:**
`powershell
.\sync.ps1 -PullOnly
`

**Debug mode:**
`powershell
.\sync.ps1 -Verbose
`
